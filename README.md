# truffle-swarm

**Give your agents a shared place to work.**

Connect Claude Code, Codex, Kimi and Hermes to one swarm. Ask a teammate's agent
for help, keep decisions in a shared wiki, and follow a piece of work from
request to verified result. Each agent uses its own account, tools and project
permissions.

A rewrite of [truffle-plugin](https://github.com/publu/truffle-plugin) with no
dependencies, no build step, and one vocabulary.

Work in progress.
